\section{Datasets and Experimental Setup}

\subsection{Datasets}
We utilize well-established reasoning datasets for training and evaluation. \textbf{Training Data:} We aggregate \textbf{MATH (Levels 3--5)} \cite{hendrycks2021measuringmathematicalproblemsolving} (5,586 multi-step problems filtered to exclude trivial tiers) and \textbf{GSM8K} \cite{cobbe2021trainingverifierssolvemath} (7,473 training problems). \textbf{Evaluation Benchmarks:} We evaluate on \textbf{MATH-500} (500 curated test problems), \textbf{AIME 2024 \& 2025} (30 elite problems each), \textbf{GPQA Diamond} \cite{rein2023gpqagraduatelevelgoogleproofqa} (198 PhD-level science questions), and \textbf{GSM8K} (1,319 test questions).

\subsection{Experimental Setup}
All experiments, including our SB-GRPO and baselines (Vanilla GRPO, M-GRPO), are conducted under a strictly controlled environment. We adopt \texttt{Qwen/}\allowbreak\texttt{Qwen2.5-7B-Instruct} as the foundational model. Under memory constraints of running a 7B model and generation engine simultaneously, we apply 4-bit QLoRA \cite{hu2021loralowrankadaptationlarge,dettmers2023qloraefficientfinetuningquantized} (\texttt{load\_in\_4bit=True}, \texttt{use\_peft=True}) with DeepSpeed ZeRO-3 and Flash Attention 2 on a single NVIDIA H100 GPU (80GB VRAM). Models are trained for 1 epoch with learning rate $1.0 \times 10^{-5}$, max prompt length 2048, and completion length 1024, generating $N=8$ completions per prompt.

\textbf{Evaluation Protocol:} To measure both peak deterministic performance and variance on small discrete test suites (e.g., AIME's 30 problems), we report both single-sample greedy decoding and multi-pass evaluation (Table \ref{tab:main}) averaged over 4 independent generation passes with distinct seeds on the trained checkpoint.

\textbf{Hardware-Aware Static Tensor Shaping:} To maximize GPU throughput on the NVIDIA H100 and completely mitigate memory fragmentation induced by variable sequence lengths, we strictly avoid dynamic padding. Building upon the variance reduction principles of DIVA-GRPO, we construct a Static Balanced Batch of a fixed size $S = 16$. Specifically, we sample $S/2$ trajectories from the Correct Pool and the remaining $S/2$ from the Top Error Cluster ($C_{\text{top}}$). By enforcing Sampling with Replacement, we guarantee that the tensor shape remains entirely constant across all training steps. This static geometric configuration minimizes memory allocation overhead, thereby fully maximizing the computational efficiency of the DeepSpeed ZeRO-3 backend under constrained VRAM environments.
